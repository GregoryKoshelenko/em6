# Урок 33 — схема підключення (реальна плата)

```
            3V3                         +V_motor (5–12 V)
             │                                │
   POT_LED ──┤ wiper → GPIO1 (ADC1_CH0)       ├──────────┐
             │                                │          │
   POT_MOT ──┤ wiper → GPIO2 (ADC1_CH1)     ┌─┴─┐      ──┴── 1N4007
             │                              │ M │       ▲   (катод до +V)
            GND                             └─┬─┘      ──┬──
                                              │          │
   GPIO4 ──[100 Ω]──►|── GND   (LED)          ├──────────┘
                                              │
   GPIO5 ──[1 kΩ]──── Gate   N-MOSFET (logic-level, напр. IRL540N)
                       Drain ─────────────────┘
                       Source ── GND (спільна з ESP32)
```

- LED: таймер LEDC 0, 5 кГц, 10 біт, канал 0.
- Двигун: таймер LEDC 1, 20 кГц, 10 біт, канал 1 → MOSFET.
- Діод 1N4007 паралельно двигуну гасить зворотну ЕРС (back-EMF) при закритті MOSFET.
- Земля джерела двигуна і ESP32 — спільна.
- Обмеження LEDC: частота × 2^роздільність ≤ 80 МГц (20 кГц × 1024 = 20.5 МГц — ок).

У Wokwi немає DC-двигуна: замість нього синій LED на GPIO5 і логічний аналізатор на GPIO4/GPIO5.
